# Phase 3O Final QA Checklist Before Production Update

Before uploading a new production AAB, test the preview APK:

- [ ] App opens without crash
- [ ] Menu opens without crash
- [ ] Sign-in wording is clean
- [ ] Admin sign-in works
- [ ] Admin panel opens
- [ ] Sponsor bar is taller/readable
- [ ] Sponsor logo fallback works
- [ ] Ad controls save and affect display
- [ ] Ad placeholders stay hidden when ads are off
- [ ] Share messages use Google Play link
- [ ] Personalized share message includes avatar/name
- [ ] Avatar picker appears and saves
- [ ] Matches tab opens
- [ ] Match filters work
- [ ] Match detail opens
- [ ] Prediction saving works
- [ ] Groups page opens
- [ ] Knockout bracket appears
- [ ] Top Predictors opens
- [ ] News opens
- [ ] Notification preferences appear
- [ ] Privacy Policy link opens
- [ ] Terms link opens
- [ ] Delete Account request opens
- [ ] Full delete helper opens but is NOT tested on admin account
- [ ] Celebration/share win appears when prediction earns points
- [ ] No crash during 5 minutes of normal use
