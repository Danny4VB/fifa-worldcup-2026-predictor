# Phase 3F - Branded Share Landing Page + Share Message Polish

## Purpose
Create a dedicated landing page for shared links:

https://hobbee.fun/worldcup-predictor

This helps WhatsApp, Facebook, Messenger, and other platforms show the FIFA WorldCup 2026 Predictor name/logo instead of the Hobbee.FUN homepage preview.

## Wix setup
1. Create a new Wix page.
2. Page title: FIFA WorldCup 2026 Predictor
3. Slug: worldcup-predictor
4. Hide from main menu if desired.
5. Use the provided HTML/text as page content, or recreate the design using Wix elements.
6. In Wix social share/SEO settings, set:
   - Title: FIFA WorldCup 2026 Predictor
   - Description: Predict WorldCup 2026 matches, choose your champion, follow groups, and compete on the leaderboard.
   - Social image: the app logo/banner image, not Hobbee.FUN logo.
7. Publish and test in an incognito browser.

## Share message standard
All app share messages should use this link:

https://hobbee.fun/worldcup-predictor

Recommended ending line:

A product of Virtual Beehive Inc., the company behind Hobbee.FUN.

## Device-aware store redirect
The provided HTML contains optional JavaScript for Android/iPhone redirect. Keep it disabled until both Google Play and Apple App Store links are ready.
