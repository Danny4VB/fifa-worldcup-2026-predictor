# Phase 4I — Smart Share / Download Link

## Purpose

The FIFA WorldCup 2026 Predictor app should not share a Google Play-only link once the app is available on both Android and iOS.

All share messages should use one smart landing/download link.

## Desired behavior

- Android visitors route to Google Play.
- iPhone/iPad visitors route to Apple App Store.
- Desktop visitors see a landing page with both buttons.

- `smart-app-download.html`
